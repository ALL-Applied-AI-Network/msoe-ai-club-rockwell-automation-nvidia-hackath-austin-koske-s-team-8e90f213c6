# Verification records

Dated JSON reports and selected smoke images from executed experiments. They
retain original file paths, hashes, runtime versions and measurement scope.
Paths in a historical record may refer to an earlier checkout layout or an
external experiment directory. Do not edit those records to imply a new run.

[Evaluation](../../docs/evaluation.md) summarizes current model evidence.
[Development](../../docs/development.md#checks) lists repeatable component checks.
[Compute setup](../../docs/compute.md) describes the launchers.

Successful imports, matching example masks and sampling QA counts establish
specific implementation checks; they are not independent real model accuracy
or approval for physical deployment.
