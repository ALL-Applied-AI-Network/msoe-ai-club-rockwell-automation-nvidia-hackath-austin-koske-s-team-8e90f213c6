    FILLING CAMERA

    Visible liquid → usable appearance evidence

    01
    Source clock + reference qualification

    Retain original frame identity. Confirm an empty reference; invalidate it on scene or camera changes.

    02
    YOLO11n → temporal U-Net

    Locate the vial, compare current/empty imagery, propose the visible liquid pool.

    03
    Optional SAM2.1 Hiera Tiny

    Refine a liquid proposal using current prompts. It does not decide whether liquid exists.

    04
    Unchanged measurement QA → RGB / Lab

    Sample original RGB only when pixel, motion and sampling checks pass.

    05
    Intended recipe + qualified reference + completion

    Recipe-aware comparison is gated by independent process evidence. Missing context stays unavailable.

    FINAL INSPECTION CAMERA

    Cap state + occupancy → placement evidence

    01
    Fixture alignment + target visibility

    Confirm the intended slot and qualified golden. Misalignment can cause false warnings.

    02
    Global reference gain → fixed slot crops

    Correct reference brightness using scene context; preserve original source imagery.

    03
    Dual-branch reference CNN · slot classification

    Classify the numbered slot crop, not a detected cap center. Crooked-cap class recall is31/38 on the demo set; body condition stays unassessed.

    04
    Attributed placement progress

    An empty slot is only a missing-placement candidate when it was expected to be occupied.

    05
    Scope and reference gates

    Current simulated poses do not cover authored lying S vials. Real accuracy is unmeasured.
