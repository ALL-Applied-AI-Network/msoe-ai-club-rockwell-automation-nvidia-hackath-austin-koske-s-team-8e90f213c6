# Synthetic Fault Evaluation

## Purpose

This module evaluates how accurately the Linewatch pipeline detects and diagnoses faults in synthetic vial-filling sessions.

It compares known synthetic fault labels (`truth.csv`) against predictions generated by Linewatch (`ledger.csv`).

## Input Files

**1. Ground truth (`truth.csv`)**

Required columns:
- `seq`: Vial sequence number
- `cause`: Actual fault cause (`none`, `carryover`, `wrong_recipe`, `dose_error`, etc.)

**2. Linewatch predictions (`ledger.csv`)**

Required columns:
- `seq`: Vial sequence number
- `rule_cause`: Predicted fault cause
- `verdict`: Fault detection verdict

## Evaluation Metrics

The evaluator calculates:

- True positives (TP), false positives (FP), true negatives (TN), and false negatives (FN)
- Precision, recall, and F1-score for fault detection
- Exact root-cause matches
- Ambiguous and unknown diagnoses
- Missing predictions and abstentions

Abstentions and missing predictions are reported separately and excluded from fault detection precision, recall, and F1-score.

## Running the Evaluator

```bash
python sim_to_real/evaluate_synthetic_faults.py \
  --truth path/to/truth.csv \
  --ledger path/to/ledger.csv \
  --out path/to/results.json
```

## Running Automated Tests

```bash
python -m unittest discover -s sim_to_real -p "test_*.py" -v
```

## Current Status

The evaluator has been validated using mock synthetic data and three automated unit tests.

Evaluation against actual synthetic production sessions is pending delivery of the new dataset.

The current evaluation metrics describe fault detection and rule-based root-cause diagnosis, not model training accuracy.
