# Team handoff, 2026-10-28

Branch `austin/line-runner`, not merged to `main`. Everything here runs on Run 5 with the released
models. No model was retrained and nothing was tuned on Run 5.

## New vs reused

**Reused unchanged:**
- **Perception:** YOLO11n vial detection, the temporal U-Net liquid mask (`temporal-cnn-v1.0.0`),
  and measurement QA.
- **Colour:** Lab measurement and ΔE2000, the recipe library and its references.
- **Deployment:** the GB10 kit and the app.

The Run 5 line run reuses the per-frame samples from the earlier model run (`--samples`). The
recipe-aware verdict and simulated-action logic builds on what the app already did per vial.

**New:**

| Piece | What it adds | Where |
| --- | --- | --- |
| Line runner | Whole-run video and recipe schedule produce, per vial: verdict, action (PASS/SCRAP/FLUSH/HOLD), issue time against the deadline, and a ledger. This replaces the per-vial check | `replay/line.py`, `replay/decide.py` |
| Annotated video | Fill camera and operator panel: live colour against reference, verdict, deadline countdowns | `replay/annotate.py` |
| Tray tracking (Dataset 1, cap_seal camera) | Counts vials into the Good/Bad trays, matches each to the vial that left the fill station, and flags missing caps. A capability we did not have before | `replay/tray.py` |
| RCA harness | An evidence packet per non-PASS vial, 6 explainer backends, schema, grounding and consistency metrics | `replay/explain.py` |
| GB10 plan | Deployment on CSI's GB10s | [deploy-gb10-line.md](deploy-gb10-line.md) |

## Per person

**Srijan, Aleyna, Reagan (training and sim-to-real)**

  real run: `python -m replay.line --video V --schedule S --library L --labels truth.csv --out DIR`.
  Report the same metrics on synthetic test and on Run 5.

  with the settings unchanged.

**Cameron, Hayden (synthetic sessions)**
- Each session needs:
  - the video;
  - `schedule.csv` (`seq,recipe_id`);
  - `labels.csv` (`vial,recipe_id,start_frame,end_frame`);
  - `truth.csv` (`seq,cause`), with causes from `CAUSES` in `replay/explain.py`: carryover,
    wrong_recipe, dose_error, missed_dose, short_fill, occlusion, vial_position, lighting, bubbles,
    no_reference.
- Highest value: a run with recipe changes, a missing water flush, one wrong recipe, a short fill
  and an occluded vial. That gives the first real decision and cause accuracy.
- Optional: a cap_seal/tray view, with a missing cap, to test tray tracking where the truth is
  known.

**Zoe (RCA and Cosmos LoRA)**

  - loaded locally: `--backend hf`.
- The bar to beat is 10/10 agreement and 20/20 consistency. The zero-shot VLMs called almost
  everything carryover.
- Train on synthetic evidence packets (`rca/vial-NN.json`) with cause labels, not on Run 5.

**Josiah (app)**
